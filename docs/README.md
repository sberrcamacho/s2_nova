# Documentation

Technical documentation for S2 Nova, kept current with the code. The
`AGENTS.md` files (root and per app) and `CLAUDE.md` hold the working rules
and stay where tools look for them.

| File | What it is for |
|---|---|
| `ARCHITECTURE.md` | Backend, database, auth, sync and deployment design; the shared business rules (e.g. goal contributions). |
| `PROJECT_STATE.md` | What is built, where it runs, test totals and known gaps. |
| `DESIGN-SYSTEM.md` | The visual source of truth for both clients, with the reasoning in its appendices. |
| `TESTING.md` | How to run the three suites, their conventions and what they don't cover. |
| `RELEASE_ANDROID.md` | How to publish the Android APK the landing page links to. |

Per-app detail: `android/AGENTS.md`, `web/AGENTS.md`, `backend/AGENTS.md`.
